## Review before you approve

| The preview shows | Detail |
| --- | --- |
| Every lead and recipient | By name |
| From address | The mailbox you chose |
| Sequence | Name and version |
| Sending window | Name, organization time zone, weekdays, local hours |

The whole selection is refused if any lead is inaccessible, closed, archived, suppressed or already enrolled, or if two leads share a recipient address. Nothing is merged for you.

## Approve

| Rule | What it means |
| --- | --- |
| One decision | Approves the complete named batch |
| Auto mode | Marro still asks for approval |
| Access | You need CRM, settings and lead access. Support and partner sessions can't enroll |
| Changes | A new name, address, sender, sequence or window means a new review |
| One failure | The whole batch rolls back |

Enrolling sends nothing by itself. Emails go out in the sending window and stop on a reply, a booking, an unsubscribe or a closed lead.

## If the connection drops

<Flow steps={["Unclear result", "Check with the same batch ID and input", "Read-only result"]} />

Checking never enrolls anyone. Don't create a new batch ID to get around an unclear result.
