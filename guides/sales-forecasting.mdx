Open **Reports → Forecast**. You need CRM Analytics and permission to view opportunities. It uses the opportunities you can see, and turning opportunities off turns forecasting off.

## Read the forecast

<Steps>
  <Step title="Choose the period">
    A start date and an end date that is not included, up to 366 days apart. For November, choose 1 November to 1 December.
  </Step>
  <Step title="Filter if you like">
    By person or pipeline.
  </Step>
</Steps>

An opportunity belongs to the period containing its expected close date.

| Figure | Meaning |
| --- | --- |
| **Open pipeline** | Full value of opportunities in open stages |
| **Weighted pipeline** | Open value times each stage's probability (default 50%) |
| **Won value** | Opportunities now in won stages, by expected close date. Not cash received |
| **Forecast** | Won value plus weighted open pipeline. Lost opportunities add nothing |

Each currency stays separate. Opportunities with no expected date, no valid value, or outside the period are counted separately. It shows current records, not a historical snapshot.

## Targets

A target is for one staff member, one exact period and one currency, across all pipelines. Only an organization administrator with CRM Analytics and settings access can set targets and open-stage probabilities. Won and lost stay at 100% and 0%.

<Steps>
  <Step title="Set the target or probability" />
  <Step title="Review the full change shown" />
  <Step title="Save">
    If someone else changed it first, refresh and review again.
  </Step>
</Steps>

| Attainment | |
| --- | --- |
| What it is | Won value against the person's target, same currency and period |
| Above 100% | Possible |
| No target, or zero | No percentage |
| Pipeline filter | Clear it first: targets cover all pipelines |
