Server-to-server access to one organization’s data in Marro. Each key belongs to an organization and can use only the scopes it was given for modules the organization subscribes to. Keys go only in the Authorization header, over HTTPS, from a server: never in browser code or a URL. A key that was ever sent over plain HTTP or in a URL must be treated as leaked: revoke it and create a new one. The API sends no CORS headers.

Every response carries `X-Request-Id`, to quote to support. Once the key is checked, responses also carry `RateLimit-Limit`, `RateLimit-Remaining` and `RateLimit-Reset` (seconds until the window resets) for whichever limit is closer to running out. An address that is not an endpoint answers 404 `NOT_FOUND` in the same error shape.

Base URL:

```text
https://app.marro.si/api
```

The full specification is an OpenAPI 3.1.0 document at [https://app.marro.si/api/openapi.json](https://app.marro.si/api/openapi.json). Import it into Postman or a client generator.

### Money

Products, quotes, invoices and payments. Amounts are integers in the smallest currency unit (paise, cents); a new document is in the organization's own currency. Tax follows the organization's regional settings: under India GST an invoice carries CGST and SGST inside the organization's state, IGST outside it, and no GST without a supplier GSTIN; under a single-rate tax (Australia GST 10%, UK VAT) each taxed line carries that tax (singleTaxMinor), and none without the supplier's registration number. Each document keeps the tax it was issued under (tax.model).

### Leads

Record-link custom fields accept numeric target ID arrays (one or up to 20 according to recordLink.multiple). Reads resolve accessible targets to id/kind/name/href objects. Deleted, archived, disabled and inaccessible targets are omitted. Destinations require the corresponding leads.read or crm.records.read scope; user destinations have no public API scope. Object destinations use object:&#60;id&#62;, require objects.records.read and the key creator current object grants.
